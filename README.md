# 🎥 AVA Video Autoplayer

A lightweight Python automation tool built with **Playwright** that automates logging in, navigating course modules, and playing video lectures sequentially on Unimestre / Portal AVA learning platforms.

## ✨ Features

- **Automated Login & Navigation**: Handles portal authentication and navigates directly to your target course and module.
- **Smart End-of-Video Detection**: Monitors HTML5 `<video>` state via JavaScript injection to seamlessly trigger the next lesson upon completion.
- **Hands-Free Learning**: Runs automatically in the background or foreground, so you can sit back while your coursework plays through.

## 🛠️ Prerequisites

- Python 3.13+
- Node.js / Playwright browsers installed
